Das Writer — Story Engine

The story-writing engine for Das Production. Claude is the brain, this MCP server is the door, the database is the memory. Every story step is saved and versioned; a finished, audit-passed screenplay ships to Notion for the Calcutta team.

Engine runs locally  ·  connect it to Claude chat after the Cloudflare deploy

The pipeline — one tool per step

create_project

Start a story from a title + replication brief. Returns the project id.

save_spine

The 4 lines: want, stakes, hero belief, villain belief. Versioned, never overwritten.

save_phases

All 8 phase one-liners in one call.

save_plants

Plant/payoff table. A plant is an orphan until its payoff scene is set.

save_scene_card

Who / want / block / turn. An empty turn is refused — a scene that doesn't turn isn't a scene.

save_scene_prose

Prose attaches to a card as a new version and re-enters draft.

approve_scene

Founder-only flip from draft to approved. Refused without prose.

get_project_state

"Where were we?" — the session memory. Call it at the start of any new chat.

Run it locally

cd das-story-engine
npm install
cp .env.example .env    # set DSE_BEARER_TOKEN
npm run dev             # → http://localhost:8787/mcp

How a story flows

  1. Brief in. You tell Claude "start a new story from this brief" — create_project makes the row.
  2. Spine locked. You iterate the 4 lines with Claude, then save with approved: true.
  3. Bones. 8 phases, then the plant/payoff table — orphan plants are tracked until paid.
  4. Scenes. Card first (must turn), prose second, founder approval third.
  5. Never lose the thread. Chat dies? New chat asks "where were we on Rooftop?" — get_project_state answers from the database.
  6. Next up (roadmap). Audit engine (plants paid, scenes turn, drafts cleared) → one-command ship to Notion.
